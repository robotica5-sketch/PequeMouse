# PequeMouse v2 — retos visuales para niños de 3 años

## Ejecutar
1. Descomprime el ZIP y abre esta carpeta en Visual Studio Code.
2. Abre Terminal > Nueva terminal.
3. Ejecuta `npm install` y luego `npm run dev`.
4. Abre la URL local indicada por Vite, normalmente http://localhost:5173.

Para probar la compilación de producción: `npm run build`.

## Incluye
- 10 retos para mover el mouse, 10 de clic, 10 de arrastrar y 10 de teclado.
- Demostraciones animadas, voz opcional, iconos grandes y retroalimentación positiva.
- Actividad de dibujo con pista punteada, paleta de colores y pincel.
- Atribución al Profesor Jhilver Eloy Quispe Barraza, Docente de Educación Inicial.

## Límites de esta versión
El progreso dura mientras la página está abierta y no se guarda en una base de datos. Los retos de teclado requieren un teclado físico. El arrastre está implementado con eventos de arrastre del navegador y requiere validación en la computadora de destino. Prototipo para probar con supervisión adulta; la autonomía debe comprobarse con niños reales.
